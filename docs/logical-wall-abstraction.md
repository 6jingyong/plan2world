# 逻辑厚墙与闭合（P20）

用户明确优先“效果可用”的算法判断。两个贴近的墙究竟是同一墙的轮廓、两面承重墙还是
管道夹层，不再是必须确认的事实。只要能保留空间使用关系，可以合成一段有效厚墙。

## 当前实现

建筑和家具观察仍各一次。家具锚点冻结后、栅格延长和功能区闭合之前，默认执行共享
`abstractCloseParallelWalls`；不依赖P19的像素候选、不新增模型调用、不修改源观察。
严格源预检、非法kind和原有精确重合恢复保持；因此预检失败不被这个算法掩盖。

- 候选为接近平行、长区间重合至少80%的实墙直线组。法向总间距最多60cm且64px，
  首尾错位使用同一局部预算；不把多个小间距串成任意宽厚墙。最多512墙、256锚点、24组。
- 新基线取全部原墙实体范围的中部，厚度覆盖原墙两侧实体外沿。墙的宽度不再统一套用
  原12cm默认。新`thicknessPx`只存在于程序trace/BareHouse，组装时统一转cm；模型观察
  不能提交这个字段。拆分段继承宽度，原生Project仍是唯一作者几何。
- 夹层内短封边可归入厚墙；相接直线沿原方向与新基线相交。开口仅在完整落于局部墙带、
  方向一致时投影，保留原长度、类型和before/after审计。不能通过删除重叠开口来合并。
- 检查每个原家具/已接受功能区种子：原闭合不丢、原分区关系不变、不新增墙体覆盖；
  逐个保留已挂接开口及宽度。原有可通行门的净空和种子间门图可达关系不得丢失。
- 能容纳直径56cm玩家的墙间净宽保留；明确功能通口即使无人也保留。air、railing和
  原生曲线不参与合并。源功能边位于新厚墙实体范围内时算逻辑覆盖，不强求中线重合。

成功组记录`logicalWallReview`，原墙审计允许多条记录指向同一组原生墙段。
其中`sourceWallIndices`指该阶段已接受wallTrace的下标；恢复前记录映射另见恢复审计。
原观察、家具坐标、门窗原端点仍保留。全图中心线拟合继续禁用。`sourceContext.wallAbstraction:
"preserve-source-lines"`只用于明确的旧逻辑对照；正常新任务采用该逻辑策略。
旧工程不会加载即重建；旧冻结阶段若与新算法不一致仍要求建立新阶段，不改旧冻结产物。

## P21：先看功能用途，再尝试合并

默认合并阶段先执行`reviewWallEnvelopeUse`，使用现有家具/功能区/入口观察，不增加提示词、
模型调用或房间类型猜测。使用证据先于原生几何对比：

- 夹层内有家具或功能区种子就保留，即使原来的墙已经盖住它；不能因原状态也有问题
  就允许继续吞掉用途标记。墙面本身的点不自动当成夹层内部点。
- 已接受和待确认的功能区都能阻止合并；待确认不会因此变成已接受几何，明确reject
  的记录不参与。原决定始终保持。
- L形等区域的种子可以在夹层外；若功能边在两面近墙上相对，且两者之间确在其轮廓
  内部，就保留这段功能区。仅共享一面外墙的普通房间、轮廓外的凹口不误判成夹层用途。
- 明确通口与横穿夹层的已观察门/门缝保留；门尚无原生宿主也有效。沿墙方向的门窗仍
  可按原规则投影。旧曲线通口按既有分段检查，原几何保持，不新增曲线编辑。

`protectedUses`记录保护原因、输入记录位置和原decision。furniture/door的路径相对于
传入的程序annotation，functional-zone/passage相对于源功能区，door-gap相对于程序trace；
不把已接受开口列表下标冒充原始混合decision列表下标。无用途证据只表示“未观察到”，
仍需通过原有宽度、闭合、开口、净空与连通约束才能合并，不断言真实构造。

不会给每组家具加墙；开放式客餐厅仍可共用一个闭合空间。已有问题继续走原标注/纠错
路径，原生Project和运行时消费方式不变。P21证据见交接页。

## 验证边界

P24将验收提取到共享`logicalGeometryConstraints`，同时用于家具和功能区闭合。
新增逐开口身份/类型/宽度、实际窗片段重叠和编译门盒体的前后比较；未完成的门检查
拒绝程序候选。用途种子包含非reject记录，待确认不会因此晋升为已接受几何。
已确认的逻辑边界继续保留并报告冲突，联合候选预算不足时不选择已评估前缀。
有限solid墙带窗口与完整限制见[共享几何验收](logical-geometry-acceptance.md)。

门图使用原生门宽和共享碰撞净空，不是实际引擎漫游、开门运动或图纸真实性结论。
未闭合、没有观察开口、非法观察以及复杂局部选择仍可能保留。算法现在只压缩重合较长的
近墙，不解决任意墙段配准或全部多缺口联合搜索。

十图同观察程序对照中，Peale合并4组，已挂接开口从2增至11（原2通口＋南侧9窗），
归一化墙29→26，原楼面三角化拒绝转为可编译。北侧6窗仍无宿主。其余9张原有结果保持，
其中NASA/办公室仍预检拒绝，FOCSA仍有家具无地面支撑。五张用户旧图未应用合并。
这是逻辑几何改进，不是新增模型识图准确率。完整原图/观察/工程字节均保留。

冻结对照与失败保存在`.plan2world-validation/runs/20261029-logical-wall-closure/`；
`complete-pixels/`为最终同像素回放；原生渲染、保存重开及机械检查输入与其几何相同。
