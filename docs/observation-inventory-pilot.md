# Compact observation pilot

The full global-inventory trials are retained in the [results ledger](observation-experiment-results.md)
(E3–E5). Complete label bookkeeping did not establish source fidelity and added
substantial duplicate output. The next trial uses the existing observation records
as the feature inventory; a separate full list and mapping report are unnecessary.

## Procedure

1. Inspect the original raster, optionally with original-pixel views. Sweep the
   exterior, shared partitions/junctions, then apertures and small service rooms.
2. Emit the existing architecture contract once. Trace shared strokes once. Use
   concise labels/evidence; a small sidecar may record only shared ownership and
   ambiguous features requiring cross-region attention. No feature quotas.
3. Observe each zone edge's `kind` explicitly. Serialization must not silently
   substitute `wall`. Keep accepted, uncertain and rejected candidates distinct.
   Choose a seed visibly inside the observed outline; a zone label is not proof
   of its perimeter or access.
4. Prefer a modest polygon trace for rounded outlines, as requested by the user.
   Preserve recesses, jambs and traversable thresholds; disclose the approximation.
   Native curves remain supported. Do not simplify authored Project geometry.
5. Freeze architecture before furniture, then freeze both before strict prepare /
   assembly, native inspection, source overlay and runtime export. A failure stays
   a failure; no in-place coordinate correction or adapter repair.
