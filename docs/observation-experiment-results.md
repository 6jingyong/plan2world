- **问题/变量**：保持 E3 方法，不改几何程序，检查复杂共享边界和服务入口。
- **输入/版本**：图2原图，生成 `b13ec2b`，结论提交 `8a69267`。
- **结果**：162/162映射、47个已接受开口全部有宿主；严格 CLI 返回成功，
  但功能区仅10/24受支持，实际 Godot 落地失败。正常 native 分析的大房间外环已有
  交叉边，不能三角化，楼板及碰撞体缺失；不能通过挪出生点补救。

  室内边类型默认成 `wall`；native/编译验收也未阻断缺失楼板。
- **决策**：保留失败，先独立补程序验收，再测试逐边显式语义；不推广大清单。
- **证据**：[斜边结果与定位](../.plan2world-validation/runs/20261024-inventory-step-4-diagonal/README.md)。
