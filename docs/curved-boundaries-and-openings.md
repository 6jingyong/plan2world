# 曲线边界与开口

源观察的 `curvePoint` 是二次 Bézier 控制点，不能只凭两端相同就认为两条路径相同。当前流程不新增模型调用、语义字段或原图中线拟合。

## 逻辑闭合

`wallPathCoverage` 在被观察的路径上计算覆盖区间，投影端点并逐段比较双向距离和切向。反向共享边及已有子段可以复用；不同弯曲方向、弦线和相邻平行边不能被视为相同路径。补边使用 `wallSubpath` 保留精确子曲线，不重新拟合或移动原始墙线。

曲线空气边界仍只允许用于阳台/室外；围栏保留可调低墙语义，通口仍需源墙端支持，并保留既有窗及物理门的范围。靠近却不重合的曲线返回 `nearby-noncoincident-curve-needs-review`，避免叠加一份近似重复边或随意合并内外轮廓。悬空墙端不属于自动补边对象。

## 原生路径与物理长度

开口保存的位置是二次曲线参数，宽度是物理距离。`openingPath` 使用既有 `wallPathProfile` 的 16 段路径，先将参数转为路径距离，再裁剪左右范围。3D、碰撞和平面图共用水平区间端点规则；仅吸收浮点运算误差，不填平真实缺口。

平面窗符号的局部横向坐标映射为路径距离，法向坐标映射为侧向偏移；每条符号线在原生路径分段处细分。现有标准窗、固定窗、推拉窗、平开窗和飘窗符号仍有各自的表达。

门洞擦除、门框和无门扇阈值沿曲线路径。铰接门扇等刚性构件使用左右门框之间的弦线及弦长，与原生 3D 的门扇规则一致。点击命中沿开口路径检查，不再命中偏离弧墙的旧切线矩形；边界框覆盖实际路径及符号装饰。

## 验证范围

合成用例覆盖部分/反向共享曲线、不同弯曲与平行曲线、空气边界/围栏/无扇通口、窗冲突保护、自由端屏风、沿曲线绘制和选中、贯穿通口的数值阻挡。真实图的程序复测必须保留输入哈希并写到新目录，标明复用冻结观察，不作为新的识图成功率证据。
