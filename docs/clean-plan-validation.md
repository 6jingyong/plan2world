# 干净平面图优先验证

P27/E28，2026-11-02。按用户新要求，主验证先使用注释较少、接近CAD出图的建筑
平面图。标注不规范、手绘或低清扫描暂时后置。原图、旧失败和兼容回归继续保留。
这是验证优先级，不改变产品导入行为。

## 入组条件

- 单层正投影图，建筑轮廓、分隔线和门洞/窗框能辨认；笔画清楚、画法相对一致。
- 注释较少，不遮挡主要几何，没有显而易见的自相矛盾标注。允许彩色、家具和透明底。
- 允许凹形、斜墙、多房间和开敞空间；不因结构复杂或程序失败而改判为“不干净”。
- 先看原图并冻结归组，再提取建筑/家具和运行程序。入组失败必须留在分母里。
- 导览示意图即使画得清楚，若缺少建筑门洞/框线细节，也单列次要组；不混入主组。

公开来源/实际像素尺寸/hash/作者/许可只放在
[`clean-plan-source-manifest.json`](../tests/fixtures/real-floorplans/clean-plan-source-manifest.json)。
里面没有墙坐标、房间答案或生成结果。独立源参考仍只能在观察、draft和叠加冻结后读取。
