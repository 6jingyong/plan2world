# 原生画作图片

添加 Wall Art 并选择墙面、朝向和安装高度后，选中它，点击 **Modify → Import picture…**。
俯视和漫游都使用现有分类修改窗口。选择本地 PNG/JPG，检查预览，可旋转90度；只有
**Apply image** 才提交。取消、无效图片或编译失败保留当前工程。**Remove picture**
只恢复通用画框，位置、尺寸、墙面、安装高度不变。

图片等比放在现有框内，留边而不裁切或拉伸。PNG透明区域保留。JPG在本地解码，预览
方向是最终方向；带EXIF方向的照片请核对预览，必要时旋转。限制8MiB、每边4096像素、
1600万像素；转成PNG后仍需满足8MiB。无需账户、网络或模型调用。

Godot负责文件选择、解码、预览；共享作者核心生成带内嵌PNG的GLB并使用现有
`customModels` / `projectPackage.assets` 保存。`purpose: wall-art-image`只决定图鉴的
贴墙复用方式；家具仍为`wall_art`，宿主、碰撞和移动契约仍由共享编译器确定。
图片变化只刷新该家具，不改建筑、出生点或其他门的开合状态。工程JSON、工程包ZIP和
运行时场景ZIP都包含图片；原图片移动/删除后仍能打开。没有保存机器路径或外部图片URL。

移除图片不会擅自删除附件或模型定义，避免破坏其他复用实例。相同图片/画框比例复用已有
附件；受现有64模型/64MiB附件预算限制。没有新增撤销/重做或操作历史。

验证包括共享核心字节/工程包/运行时ZIP往返、实际Godot PNG/JPG解码与颜色检查、取消/
应用、删除原图片后的保存重开、移除图片和真实窗口截图。测试包的Windows CI执行与
Windows显卡/键鼠硬件验收分开记录。
