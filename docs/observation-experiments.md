## Evidence views (optional)

```sh
node tooling/plan2world-source-views.mjs \
  --source original.jpg --output NEW_DIRECTORY --grid 3x3 --overlap 32
```

This copies original RGBA pixels into lossless views with source boxes, disjoint
core boxes and hashes; no enhancement, rotation, fitting or alternate coordinates.
It refuses existing output. E1 verifies pixel/stability behavior. E2 did not show
an overall extraction gain, so views remain optional rather than a quality gate.

## What transfers from img2threejs

The inspected [upstream revision](https://github.com/img2threejs/img2threejs/tree/954cd5845e90efd045694bab725d68a9863c20e0)
uses a deterministic factory from a model-authored spec. Its
[detail-inventory tool](https://github.com/img2threejs/img2threejs/blob/954cd5845e90efd045694bab725d68a9863c20e0/forge/stage1_intake/build_detail_inventory.py)
prepares views and unfilled stubs; it does not detect or score features.

Absorb source-region inspection, evidence that maps to actual structured outputs,
stage ownership and explicit gaps. Recognition, cabinet-versus-wall judgments,
jambs, scale anchors and occluded shape still depend on the model. More records
and self-reported scores do not establish accuracy; E3–E5 exposed that limit.

Do not import feature quotas, subjective scores as acceptance gates, camera fitting
that hides coordinate errors, repeated geometry polishing, sculpting/material/rig
subsystems, or another canonical representation. Plan2World already owns its
observation → native Project → engine-neutral compilation boundary.

## Program acceptance stays separate

ground/aperture boundaries before shared runtime export writes artifacts. It does
not repair failed source observations. M1 demonstrates the existing `passage` contract
with synthetic inputs; E5's real-image semantic ablation remains inconclusive.
Do not fill missing floors, relocate spawn or infer geometry in Godot.
