# 门窗与墙带联合诊断（P19）

P18解决了合法结果被连带丢失的问题，没有改善源图提取。P19继续第二阶段：从原图像素
检查已观察门窗附近的物理墙带和完整框边，先作为显式、只读实验，不接入正常重建。
它只检查已有开口提示；模型漏掉的门窗不会由本工具自动发现。

## 为什么要换读图对象

厚墙可能画成黑色实心带，也可能只有内外两条细轮廓。白色带内没有黑像素不代表没有墙，
两条轮廓也不必然代表两面独立墙。Peale博物馆的窗在墙带内部，部分原墙记录沿轮廓走，
南侧还同时记录了两面；把窗吸附到任意一条线不能解决物理墙表示错误。

源端点也可能落在窗体内部。Peale一处新像素框边候选比原左端点外扩38px；这是诊断
测量，不是修改源坐标，也不增加宿主匹配容差。需要把墙、门窗框和两侧墙垛一起核对。

## 方法与边界

- 使用既有55/95/135对比度中性墨迹掩码。新RGBA诊断按整幅图估计背景，避免把一条
  实心墙条当成页面背景；旧冻结掩码按其已有背景重放，缺少三档或背景不明时不出候选。
- 以原开口方向建立局部坐标，搜索范围受图像边界、64px法向半径和开口长度约束。
  两侧各8个截面需有一致轮廓。实心墙检查开口处的墨迹中断；轮廓墙检查内部窗线或
  门洞的轮廓中断。空矩形和两条平行走廊线本身不充分。
- 框边独立在原端点附近搜索，最多为原长度的60%、且不超过64px；需跨墙带覆盖至少
  80%的像素证据，再重新检查检测框边外侧的墙垛。搜索到多对框边或多条墙带时保留多解。
- 三档掩码必须支持同一墙带和框边。没有“最近候选胜出”、强制闭合、改墙、开口改绑、
  新门窗、入口猜测或额外LLM请求。新多边形可任意朝向，不引入曲线编辑。

输出`source-aperture-wall-band-review-v1`，方法`local-paired-faces-and-pixel-jambs-v2`。
包含每条原开口的候选局部带、框边偏移、三档实测支持、拒绝理由和相关原墙记录。
`existingHostStatus`仅表示原始墙线、归一化之前的关联，不是已保存工程的宿主验收。
状态`unapproved-wall-band`与`baseline-consistent`都不表示源图正确。

诊断不返回draft、annotation、normalizationInput或替换墙线；默认生成与原生核心不导入
该模块。观察记录与Project保持原字节，既有全图中心线自动修正仍禁用。

## 使用

```bash
npm run source:apertures -- \
  --project frozen.project.json --source working.png --output new-review-directory
```

Project必须保留原观察和工作图SHA。诊断读取其中冻结的历史观察；后续人工修改保留在
原工程中，诊断不能当成当前原生几何的验收。也支持独立冻结观察：

```bash
npm run source:apertures -- \
  --observations architecture.json --source working.png \
  --source-sha256 CONFIRMED_WORKING_IMAGE_SHA256 --output another-new-directory
```

图像身份不符、缺少原观察或输出目录已存在均拒绝。父目录可自动建立，不覆盖任何输入。
输出诊断JSON、身份provenance和独立`review.html`；可选择门窗、切原图/叠图、看原像素
局部及橙色未应用墙带/框边。页面没有确认几何或自动应用入口。

## 实际结果与决定

用P18原观察和原图检查五张公开图，再检查五张用户旧图，未重新调用模型：

- Peale的15个原无宿主窗中14处有三档一致的局部候选，剩余1处证据不足；另有1个原
  通口与观察基线一致，1个通口证据不足。14/15是候选覆盖，**不是识别准确率或修复率**。
- NASA仅1处基线一致，其余9处证据不足、2条kind非法；低清办公室3处均证据不足。
  FOCSA有9处一致、3处不足、1处原不确定；Kumaya没有源开口，仍不造室内细节。
- 用户旧图没有新的唯一墙带纠错候选，大户型有1处多解。黑底7处不足、4处原不确定，
  继续尊重矛盾暗门豁免。全部工程/原图不改，当前源验收状态不变。

因此保留为局部几何研究工具，暂不推广成通用自动修图算法。局部线条可与家具、窗框
或狭窄通道同形，像素支持不足以确认语义。更合理的下一步是让建筑观察确认“一段物理
墙带及开口粗区域”，程序或专用视觉模型计算几何；先在填充墙、轮廓墙、低清图分别验证，
再决定观察合同和默认流程的改造。结构约束、人工修正量和源准确性继续分开评价。

冻结证据：`.plan2world-validation/runs/20261028-aperture-wall-bands/`。早期固定端点搜索
只能覆盖Peale的12处；独立框边搜索后为14处。原结果、背景采样负例和命令失败均保留。
