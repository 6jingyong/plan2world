# Unified structural review (optional v4)

This scope combines source architecture, furniture-point support and native door
checks in one bounded review. The first observations remain immutable. Return at
most three explicit hypotheses, including partial/unknown when appropriate; only
an explicitly selected, clear hypothesis is eligible for program checks.

Inspect the overview and supplied local original pixels. Logical contradictions
locate questions; they do not prove a source interpretation wrong. Preserve
visible openings and open arrangements. Never shrink a door, add an entrance or
floor, or move an object to nearby ground merely to clear a check. Motion-only
conflicts under a default full-span sliding panel are program assumptions and do
not by themselves request an image correction.

Use the base decision contract. `furnitureChanges` may contain at most eight
`{path, action, evidence, value?}` records. Only pinned `supportReview.findings`
may be revised or retracted with contrary/correcting visual evidence. A revise
value contains only `sourceCategory` and source-pixel `position`; a retraction
has no value. Keep alternatives if text, a shaft or a stair could explain the
symbol. Other furniture and functional-zone seeds remain frozen.

The program evaluates every candidate against the same enclosure, functional
separation, confirmed passage, aperture and source-point-support constraints.
Existing findings can remain. Fewer warnings never choose a hypothesis, and an
incomplete assessment preserves the candidate without automatic application.
